# GPA Tracker

A simple Java console program that calculates your GPA from your module results.

## Features
- Enter your name, university and degree
- Add any number of modules with a grade and credits
- Rejects invalid grades and credit values
- Prints a summary with your final GPA

## How to run
    javac GpaTracker.java
    java GpaTracker

## Example
Maths (A, 3 credits) and Physics (B+, 4 credits) give a GPA of 3.60.

## What I used
Java: classes, ArrayList, Map, Scanner, loops and input validation.
